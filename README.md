## 🎮 Game Description

Cyber Adventure is a 10-level school-themed interactive story game** that teaches cybersecurity awareness** in a fun and engaging way. Players make choices as Crispulo Perez, guided by Ma'am Arlyn, and see GIF animations, sound feedback, and educational tips at every level.  

## 🛠 Technologies Used

- HTML5  
- CSS3  
- JavaScript 
- Git & GitHub  

## 🕹 How to Run the Game

1. Clone or download the repository  
2. Open the folder `DC101_Game_PerezCrispulo`  
3. Open `index.html` in your browser  
4. Click Start Adventure  
5. Play through all 10 levels and make choices
